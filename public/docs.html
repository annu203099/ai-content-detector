Architecture Guide

Overview & System Architecture

The AI Detector SDK is a local-first forensic suite engineered to run high-confidence multimodal AI evaluations without sending payloads to external clouds.

Modern enterprise applications face stringent data residency constraints (GDPR, HIPAA, SOC 2). Sending proprietary source code, healthcare notes, or customer imagery to remote AI detection APIs introduces latency and compliance liabilities. This SDK bundles quantized transformer models that execute inside the host runtime via ONNX Runtime WebAssembly and Node.js.

Core Architectural Components

  • Text Classification Core: Fine-tuned DistilBERT INT8 sequence classifier trained on diverse synthetic LLM distributions paired with empirical statistical token modeling.
  • Vision Classification Core: Sieve Vision Transformer (ViT-S/16) fine-tuned from Community Forensics on native 384x384 patch representations.
  • Cryptographic C2PA Validator: Native parser for Coalition for Content Provenance and Authenticity (C2PA) JUMBF boxes to verify camera origins vs. synthetic generation manifests.
  • Calibration Engine: Platt scaling and temperature calibration that outputs mathematically grounded posterior probabilities $P(\text{AI})$ with uncertainty bands.

Installation & Dependencies

Install the SDK via your preferred package manager. The package ships with zero mandatory native binaries for pure WASM mode, and leverages pre-built bindings for Node.js acceleration.

Terminal 
npm install @annapurna12/ai-detector

Node.js High-Throughput Accelerators

For maximum Node.js server throughput, install sharp for SIMD image decoding and @contentauth/c2pa-node for cryptographic provenance verification: 

npm install sharp @contentauth/c2pa-node onnxruntime-node

Quick Start Guide

Get started with zero configuration using the top-level detectText helper, or instantiate AIDetector for persistent model caching and lifecycle management.

import { AIDetector, detectText } from '@annapurna12/ai-detector';
example.ts 
import { AIDetector } from '@annapurna12/ai-detector';
import fs from 'node:fs/promises';

// Initialize unified detector (lazy sessions, cached weights)
const detector = new AIDetector({
  runtime: 'node-cpu', // or 'wasm'
  provenance: true
});

// 1. Text Analysis
const textResult = await detector.detectText(
  'The systematic integration of transformer architectures facilitates multifaceted reasoning...'
);

console.log(textResult.verdict);    // 'likely_ai'
console.log(textResult.confidence); // 0.985
console.log(textResult.perplexity); // 14.2

// 2. Image & Provenance Analysis
const imageBuffer = await fs.readFile('./upload.jpg');
const imageResult = await detector.detectImage(imageBuffer);

console.log(imageResult.verdict);          // 'likely_human' | 'likely_ai' | 'uncertain'
console.log(imageResult.provenance.status); // 'none' | 'validated_ai' | 'validated_edit'
Documentation / Text Detection / DistilBERT Pipeline
Methodology

DistilBERT Text Detection Pipeline

Text detection utilizes a quantized DistilBERT transformer combined with token-level statistical metrics. Long documents are segmented into 512-token chunks with a 64-token stride to preserve context across boundaries.

Perplexity & Burstiness Signals

LLM-generated prose exhibits characteristic statistical homogeneity:

  • Perplexity ($PPL$): Measures the surprise of the model when predicting tokens. Machine-generated text clusters in lower perplexity bands because standard decoding strategies prioritize probable tokens.
  • Burstiness ($BST$): Measures sentence-to-sentence variance in length and complexity. Human authors naturally alternate short punchy sentences with intricate compound structures, yielding high burstiness.

Batch Processing

textBatch(texts: string[], options?: TextDetectorOptions): Promise<TextDetectionResult[]>

Evaluates multiple text documents in parallel while reusing the warmed ONNX session, achieving up to 4.2x higher throughput than sequential execution.

Documentation / Image Detection / Vision Transformer
Deep Learning

ViT-S/16 Vision Pipeline

Image forensics employs an INT8-quantized Vision Transformer (image.sieve.ft1.int8, fine-tuned from Community Forensics). The network splits images into $16 \times 16$ non-overlapping patches to detect generative diffusion artifacts, upscaler grid anomalies, and frequency-domain synthetic traces.

Strict Preprocessing Protocol

To guarantee zero false positives on genuine camera photos, image inputs must follow the exact upstream Community Forensics specification:

  • Shortest-Edge Scaling: The shorter side of the image is scaled to 440 pixels with bilinear antialiasing.
  • Center Cropping: A clean 384 x 384 pixel square is cropped from the center, preserving high-frequency camera sensor noise.
  • ImageNet Normalization: Pixel values in $[0, 1]$ are standardized with:
    mean = [0.485, 0.456, 0.406], std = [0.229, 0.224, 0.225]

C2PA Cryptographic Provenance

Before visual tensor inference, the SDK inspects embedded JUMBF metadata structures for Content Credentials. If a cryptographically signed claim asserts c2pa.trained_algorithmic_media (from Adobe Firefly, Midjourney, DALL-E), provenance immediately reinforces the verdict with tamper-evident certainty.

Documentation / API Reference
API Specification

class AIDetector

The primary entry point that coordinates model loading, session caching, and modality dispatch.

class AIDetector(options?: AIDetectorOptions)
Option Type Default Description
runtime 'node-cpu' | 'wasm' | 'webgpu' 'node-cpu' (Node) / 'wasm' Execution provider target for ONNX Runtime.
provenance boolean true Whether to inspect embedded C2PA/EXIF metadata.
mode 'online' | 'strict-offline' 'online' In offline mode, throws if weights are not in local cache.

detector.detectText()

async detectText(text: string, options?: { threshold?: number }): Promise<TextDetectionResult>
Parameter Type Description
text string The plain text payload to inspect (minimum 5 words recommended).
options.threshold number (0.0 to 1.0) Operating classification threshold (defaults to model manifest: 0.50).

detector.detectImage()

async detectImage(input: ImageInput, options?: { threshold?: number, provenance?: boolean }): Promise<ImageDetectionResult>
Parameter Type Description
input Buffer | Uint8Array | ArrayBuffer | Blob | string (path) The image input in JPEG, PNG, or WebP format.
options.threshold number Operating classification threshold (defaults to model manifest: 0.65).

TypeScript Interfaces

export type Verdict = 'likely_human' | 'likely_ai' | 'uncertain' | 'insufficient_evidence';

export interface TextDetectionResult {
  id: string;
  modality: 'text';
  status: 'ok' | 'inference_error';
  verdict: Verdict;
  confidence: number;    // Calibrated probability in [0.0, 1.0]
  perplexity: number;    // Token perplexity metric
  burstiness: number;    // Sentence variance metric
  timing: { totalMs: number; inferenceMs: number };
}

export interface ImageDetectionResult {
  id: string;
  modality: 'image';
  status: 'ok' | 'inference_error';
  verdict: Verdict;
  confidence: number;    // Calibrated probability in [0.0, 1.0]
  score: number;         // Raw model logit
  provenance: {
    status: 'none' | 'validated_ai' | 'validated_edit' | 'present_unknown';
    source?: string;
  };
  timing: { totalMs: number; preprocessingMs: number; inferenceMs: number };
}
Documentation / Deployment / Production Integration
Production

Production Server Integration

Integrate the SDK into an Express or Fastify microservice to serve internal corporate verification endpoints with zero cloud dependencies.

server.ts 
import express from 'express';
import { AIDetector } from '@your-scope/ai-detector';

const app = express();
const detector = new AIDetector({ runtime: 'node-cpu' });

// Text verification route
app.post('/api/verify/text', express.json(), async (req, res) => {
  const result = await detector.detectText(req.body.text);
  res.json(result);
});

// Image verification route
app.post('/api/verify/image', express.raw({ type: 'application/octet-stream', limit: '20mb' }), async (req, res) => {
  const result = await detector.detectImage(req.body);
  res.json(result);
});

app.listen(8080, () => console.log('AI Detection API active on :8080'));

Air-Gapped & Offline Packaging

For deployment in restricted intranet environments where outbound internet is disabled:

  1. Pre-download model weights to ~/.cache/ai-detector/ai-detector-models-v1/ during container build.
  2. Set mode: 'strict-offline' when initializing AIDetector.
  3. The SDK will bypass all network fetches and load local weights with cryptographic SHA-256 integrity verification.
