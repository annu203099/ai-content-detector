Enterprise Architecture

Engineered for Accuracy and Compliance

Purpose-built for organizations that demand total data privacy without compromising detection fidelity.

100% On-Device Execution

Inference runs locally using ONNX Runtime. Confidential user text and proprietary media never leave the user machine, fulfilling strict GDPR and HIPAA requirements.

C2PA Cryptographic Provenance

Extracts and audits Coalition for Content Provenance and Authenticity (C2PA) JUMBF claims. Detects digital certificates from Adobe, OpenAI, and Leica.

Sieve ViT-S/16 Vision Model

Trained on multi-generator artifacts with shortest-edge 440 scale and ImageNet normalization. Distinguishes camera sensor noise from diffusion synthesis.

DistilBERT & Perplexity Heuristics

Combines 66-layer transformer token classification with sentence burstiness analysis and bigram entropy to expose repetitive syntax patterns.

Sub-150ms Local Latency

Eliminates the 1,500ms network round-trip of cloud APIs. Execute high-throughput batch evaluations at zero marginal infrastructure cost.

Cryptographic Model Integrity

Built-in SHA-256 manifest verification prevents supply-chain model tampering. Models are validated before any weights load into host memory.

Developer Quickstart

Production-Ready in Minutes

1

Install the package

npm install @annapurna12/ai-detector
2

Analyze Text Content

import { AIDetector } from '@annapurna12/ai-detector';

const detector = new AIDetector();
const result = await detector.detectText('Content to inspect...');

console.log(result.verdict);    // 'likely_human' | 'likely_ai' | 'uncertain'
console.log(result.confidence); // 0.0 to 1.0 calibrated posterior probability
3

Inspect Image & C2PA Provenance

import fs from 'node:fs/promises';

const imageBuffer = await fs.readFile('photo.jpg');
const imageResult = await detector.detectImage(imageBuffer);

console.log(imageResult.provenance.status); // 'validated_ai' | 'none'
console.log(imageResult.evidence.pixelModel); // ViT-S/16 confidence
